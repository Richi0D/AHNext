# Antenna Helper Next

This is a complete rework of LiOn-0 original mod ***[Antenna Helper](https://github.com/Li0n-0/Antenna-Helper)*** and from the forked and maintained version of linuxgurugamer ***[Antenna Helper](https://github.com/linuxgurugamer/Antenna-Helper)***.

It fixed various issues the original mod had.

- Complete redone of the code base.
- GUI rework.
- Reworked updates of Vessels during flight. (No more *"Antenna Helper isn't ready just yet. Wait..."*).
- Always have a complete list of editor vessels instead of saving it to a temporary list.
- **New 3D Spheres for Range visualization** (Big thanks goes to *Kerbalism* mod for the idea of point clouds)
- Many more small fixes and improvements.

## Compatilibity

Not compatible with the original mod. Uninstall the original mod before installing this one.
Other than that it should work with most mods if they do not modify the calculation of the antenna ranges. 

**DEPENDENCY :**
* [Toolbar Controller](https://github.com/linuxgurugamer/ToolbarControl/releases)
